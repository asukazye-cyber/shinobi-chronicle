# Cenários

Coloque aqui fundos de locais persistentes: vila natal, Academia, áreas de
treino, arenas de torneio, fronteiras e salas importantes.

Use **1920 × 1080 px, WebP, 16:9**. Consulte `../README.md` para regras de
enquadramento, nomenclatura e peso.

Exemplos de slots que serão usados quando a camada visual de cenários for
conectada à interface:

```text
hoshigakure-academy.webp
kazan-training-ground.webp
mizuhara-waterfront.webp
sunae-arena.webp
kurogane-council.webp
vale-das-pontes.webp
cupula-das-cinco-rotas.webp
```
